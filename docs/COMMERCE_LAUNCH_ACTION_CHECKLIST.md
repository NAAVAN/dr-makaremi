# چک‌لیست جامع اقدام‌های تکمیلی و راه‌اندازی فروش آنلاین (`MAKAREMI-CORE-2026`)

> **هدف این سند:** گردآوری یکپارچه و گام‌به‌گام تمامی کارهای باقی‌مانده (ثبت‌نام‌ها، دریافت کلیدها، تنظیمات دیتابیس، امنیت پیشخوان، ایمیل، کارهای سوپرادمین و اقدام‌های حقوقی/بانکی/هنری استاد دکتر حسن مکارمی در فرانسه) تا زمان شروع فروش رسمی و دریافت وجه واقعی.
>
> **هشدار امنیتی:** هرگز مقادیر واقعی رمزها، کلیدهای API (`sk_live_...`, `whsec_...`, `re_...`) یا رشته `DATABASE_URL` را داخل این فایل یا مخزن Git ذخیره نکنید؛ تمامی مقادیر محرمانه صرفاً در **Password Manager** شخصی و بخش **`Environment Variables` در Vercel** نگهداری شوند.
